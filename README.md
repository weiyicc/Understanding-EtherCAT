# 最好理解的 EtherCAT

《最好理解的 EtherCAT》系列配套资料，按期数整理参考图、Wireshark 抓包样本和倍福官方手册下载链接。

## 目录

| 目录 | 内容 |
| --- | --- |
| [001_认识EtherCAT/](001_认识EtherCAT/) | 第 1 期资料目录，待补充 |
| [002_硬件层/](002_硬件层/) | 第 2 期资料目录，待补充 |
| [003_数据包结构/截图/](003_数据包结构/截图/) | 数据包结构、寻址方式、WKC 等参考图，共 10 张 |
| [003_数据包结构/抓包/](003_数据包结构/抓包/) | [Linux.pcapng](003_数据包结构/抓包/Linux.pcapng)、[ECT抓包40轴.pcapng](003_数据包结构/抓包/ECT抓包40轴.pcapng) |
| [004_ESC通识/](004_ESC通识/) | [倍福 ET1100 从站控制器手册下载](004_ESC通识/ETH1100%20ESC%20datasheeet.md)。第一部分介绍 ESC 工作原理，包括 FMMU、同步管理器和分布式时钟。第二部分是寄存器说明，第三部分是 ET1100 硬件特性。 |

第 004 期开头的广播写可以在 `Linux.pcapng` 的第 1 帧找到。用 Wireshark 展开 EtherCAT 子报文，找到目标地址 `0x0103` 和写入值 `0x00`，就可以对照手册第二部分查这个地址的含义。

前两期目录中的 `.gitkeep` 用于保留空目录结构。资料会随系列内容继续补充。
